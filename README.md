YouTube Trending Videos - Análisis Exploratorio

Descripción
En este proyecto se analizaron la relación entre Vistas y Likes,
así como el Top 10 de Canales más vistos.
Se utilizaron las librerias Pandas, Matplotlib y Seaborn para
hacer un análisis EDA completo.
Se muestra la correlación entre los videos más vistos con la cantidad
de Likes que llegan a tener.

Preguntas que se responden.
- ¿Qué canales aparecen más en el Trending?
- ¿Qué categorías generan más vistas?
- ¿Qué dias hay más videos trending?
- ¿Cuál es la relación entre vistas y likes?
- ¿Qué videos tienen la audiencia más comprometida?

## Tecnologias utilizadas
- Python 3.9
- pandas
- matplotlib
- seaborn

## Dataset
[YouTube Trending Videos - Kaggle](https://www.kaggle.com/datasets/datasnaek/youtube-new)

## Cómo ejecutarlo
1. Clona el repositorio
2. Instala las dependencias:
```bash
pip install pandas matplotlib seaborn
```
3. Ejecuta el archivo:
```bash
python youtube_analysis.py
```
